# 常见设计陷阱 (Common Pitfalls)

## 目录说明

本目录收集**场景设计中容易犯的错误和反面教材**，帮助开发者避免重复踩坑。

每个文档记录一个具体的设计陷阱，包括：
- **问题描述**：陷阱是什么
- **实际案例**：在哪个场景中出现过
- **影响范围**：导致了什么问题（失败模式、样本数量）
- **根本原因**：为什么会出现这个问题
- **解决方案**：如何修复
- **通用原则**：从这个案例中提炼的设计原则

## 使用场景

**在场景设计阶段**：
- 设计Business Rules前，先浏览本目录，了解已知的陷阱
- 编写完规则后，对照这些陷阱进行自检

**在失败分析阶段**：
- 发现新的设计陷阱时，记录到本目录
- 更新已有陷阱的影响范围和案例

## 贡献指南

发现新的设计陷阱时，请创建新文档，遵循以下模板：

```markdown
# [陷阱名称]

## 问题描述

简洁描述这个设计陷阱是什么。

## 实际案例

**场景**：[场景名称]
**失败模式**：[FP编号和名称]
**影响样本数**：X/Y (Z%)

### 具体表现

[详细描述问题如何体现]

## 根本原因

[分析为什么会出现这个问题]

## 解决方案

### 修改前

[展示错误的设计]

### 修改后

[展示正确的设计]

## 通用原则

从这个案例中提炼的可复用设计原则：

- ✅ [正确做法]
- ❌ [错误做法]

## 相关资料

- [链接到manual annotation文件]
- [链接到分析报告]
```

## 与其他文档的关系

- **SKILL.md**：主文档，描述如何正确设计场景
- **common_pitfalls/**：本目录，描述如何避免错误设计
- **examples/**：正面示例，展示优秀的场景设计
- **references/**：参考资料，深入的设计模式说明
